# dotfiles
## Install
Run:
```
curl -fsSL https://haru067.com/dot | sh
```
/dot is alias for install.sh on the main branch

Git identity is not in this repository, which is public. Create `~/.gitconfig.local` on each machine:

```
[user]
	name = your-name
	email = you@example.com
```

## Overview
  * /src - Used in install.sh, automated
  * /app - Require manual install for each apps
  * /dein - vim
